# My Grades — A+ Dashboard

A cheerful, responsive school grades dashboard built as a single static HTML page. Every subject shows an A+, and clicking a subject updates the detail card.

## Run locally

Open `index.html` in any modern web browser. There are no dependencies or build steps.

The sample subjects are Mathematics, English, Science, History, Art, and Physical Education. Edit the `subjects` array in `index.html` to customize them.
